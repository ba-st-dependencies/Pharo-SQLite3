This project is a mirror of [pharo-rdbms/Pharo-SQLite3](https://github.com/pharo-rdbms/Pharo-SQLite3)
intended to be used as a stable dependency on [Buenos Aires Smalltalk](https://github.com/ba-st)
projects.

The `release-candidate` branch can be used as a stable dependency and the `upstream`
branch is mirroring the default branch of the upstream repository.
